# Phase 8: Final Documentation & Deployment

### Project Description (Final for README.md):
Managing budgets across home decor, event planning, jewelry is overwhelming. PocketSmart AI addresses via GenAI cross-platform system using Gemini 1.5 Flash Pro. Analyzes preferences, budgets, needs to generate curated recommendations from Amazon, Flipkart, IKEA, Swiggy, Zomato, OYO.

### Core Technologies:
- Flask/FastAPI: Backend service layer
- Gemini 1.5 Flash Pro: AI model for understanding & suggestions
- Frontend: HTML/CSS + JS
- Third-party: Amazon, IKEA etc.

### 3 Scenarios Covered:
1. Home Interior Planning
2. Party Budget Planning
3. Jewelry Recommendations

### Deployment:
- Requirements: IBM Cloud, Watsonx, Python Basics, FastAPI
- Run: `uvicorn app.main:app --host 127.0.0.1 --port 8000`
- Docs: http://127.0.0.1:8000/docs (Swagger)
